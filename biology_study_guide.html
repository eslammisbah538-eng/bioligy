عضيات الخلية · الأنسجة · الشعبات (Phyla)

🔋 عضيات الخلية — Cell Organelles

🟢 Mitochondria
Def
Double-membrane organelle — the powerhouse of the cell.
عضية ذات غشاءين — محطة طاقة الخلية.
Structure
Outer membrane + inner folded membrane (cristae) + matrix inside.
غشاء خارجي + غشاء داخلي مطوي (كريستا) + مصفوفة بالداخل.
Function
Produces ATP energy by cellular respiration.
تُنتج طاقة ATP عن طريق التنفس الخلوي.
⚪ Ribosome
Def
Tiny non-membrane organelle made of rRNA + protein.
عضية صغيرة بدون غشاء من rRNA + بروتين.
Structure
Two subunits (large + small). Free in cytoplasm or on rough ER.
وحدتان فرعيتان (كبيرة + صغيرة). حرة أو على ER الخشن.
Function
Protein synthesis (translation).
تصنيع البروتين (ترجمة).
📦 Golgi Apparatus
Def
Stack of flattened membranes (cisternae).
طبقات أغشية مسطحة (صهاريج).
Structure
Cis face (receives) → Trans face (ships out). Produces vesicles.
Cis يستقبل ← Trans يُرسل. ينتج حويصلات.
Function
Processes, packages, and secretes proteins and lipids.
يعالج ويعبّئ ويُفرز البروتينات والدهون.
🔀 Endoplasmic Reticulum (ER)
Def
Network of membranes connected to the nucleus.
شبكة أغشية متصلة بالنواة.
Structure
Rough ER (has ribosomes) + Smooth ER (no ribosomes).
ER خشن (بريبوسومات) + ER ناعم (بدون).
Function
Rough → proteins. Smooth → lipids + detox.
الخشن ← بروتينات. الناعم ← دهون + إزالة سموم.
🟡 Lysosome
Def
Membrane sac filled with digestive enzymes.
كيس غشائي مليء بإنزيمات هاضمة.
Structure
Single membrane, acidic inside (pH ~5).
غشاء واحد، حمضي من الداخل (pH ~5).
Function
Digests waste, old organelles, and foreign particles.
يهضم الفضلات والعضيات القديمة والجسيمات الغريبة.
🔵 Nucleus
Def
Control center of the cell.
مركز التحكم في الخلية.
Structure
Nuclear envelope (double membrane) + pores + nucleolus + chromatin (DNA).
غلاف نووي (غشاءين) + مسام + نوية + كروماتين (DNA).
Function
Stores DNA, controls cell, produces rRNA in nucleolus.
يخزّن DNA، يتحكم في الخلية، ينتج rRNA في النوية.
⚙️ Centriole
Def
Cylindrical structure made of microtubules.
تركيب أسطواني من أنابيب دقيقة.
Structure
9 triplets of microtubules arranged in a ring.
9 ثلاثيات من الأنابيب الدقيقة في حلقة.
Function
Forms spindle fibers during cell division.
يُكوّن خيوط المغزل أثناء انقسام الخلية.
💧 Vacuole
Def
Membrane-bound sac for storage.
كيس غشائي للتخزين.
Structure
Single membrane (tonoplast). Large in plants, small in animals.
غشاء واحد (توناوبلاست). كبير في النبات، صغير في الحيوان.
Function
Stores water, waste, food, or ions.
يخزّن الماء والفضلات والغذاء والأيونات.
🧠 الغشاء — كم غشاء؟
غشاءين: Mitochondria + Nucleus
غشاء واحد: Lysosome + Vacuole + Golgi (حويصلاته)
بدون غشاء: Ribosome + Centriole
🔤 جملة الحفظ: M R G E L N C V
"ميتو ريبو جولجي إندو ليزو نواة سنتريول فاكيول"
كل حرف = عضية!

🧫 الأنسجة — Animal Tissues

🔲 Epithelial Tissue — نسيج طلائي
Def
Sheets of tightly packed cells lining body surfaces and cavities.
طبقات من خلايا متراصة تُبطّن أسطح الجسم والتجاويف.
Key Features
NO matrix • NO blood vessels • Cells tightly packed • Has basement membrane.
بدون مصفوفة • بدون أوعية دموية • خلايا متراصة • له غشاء قاعدي.
Types
Simple (1 layer) vs Stratified (multiple layers). Squamous / Cuboidal / Columnar.
بسيط (طبقة واحدة) vs متعدد الطبقات. حرشفي / مكعبي / عمودي.
Function
Protection, absorption, secretion, sensation.
الحماية، الامتصاص، الإفراز، الإحساس.
Examples
Skin (stratified squamous), intestinal lining (simple columnar), kidney tubules (cuboidal).
الجلد، بطانة الأمعاء، أنابيب الكلى.
🔶 Connective Tissue — نسيج ضام
Def
Tissue that connects, supports, and binds other tissues.
نسيج يربط ويدعم ويوصل الأنسجة الأخرى.
Key Features
HAS matrix (extracellular) • HAS blood vessels • Scattered cells in matrix.
له مصفوفة خارج خلوية • له أوعية دموية • خلايا مبعثرة في المصفوفة.
Types
Loose CT • Dense CT • Cartilage • Bone • Blood.
ضام رخو • ضام كثيف • غضروف • عظم • دم.
Function
Support, bind, transport (blood), store fat (adipose).
الدعم، الربط، النقل (الدم)، تخزين الدهون (الدهني).
Examples
Tendons (dense), cartilage, bone, adipose tissue, blood.
الأوتار، الغضروف، العظم، الدهون، الدم.
💪 Muscle Tissue — نسيج عضلي
Types
1. Skeletal (striated, voluntary) — 2. Cardiac (striated, involuntary, branched) — 3. Smooth (non-striated, involuntary).
١. هيكلي (مخطط، إرادي) — ٢. قلبي (مخطط، لا إرادي، متفرع) — ٣. أملس (غير مخطط، لا إرادي).
Function
Movement, pumping blood (cardiac), peristalsis (smooth).
الحركة، ضخ الدم (القلبي)، التمعج (الأملس).
⚡ Nervous Tissue — نسيج عصبي
Cells
Neurons (transmit signals) + Glial cells (support, protect neurons).
خلايا عصبية (تنقل الإشارات) + خلايا دبقية (تدعم وتحمي العصبية).
Structure of Neuron
Dendrites (receive) → Cell body → Axon (transmit) → Synapse.
تشعبات (تستقبل) ← جسم الخلية ← محور (ينقل) ← متشابك عصبي.
Function
Transmit electrical signals throughout the body.
نقل الإشارات الكهربائية في الجسم.

🦑 شعبات المملكة الحيوانية — Animal Phyla

🟤 Porifera — المسامية (الإسفنج)
Key ID
Body full of pores (ostia). No true tissues or organs.
الجسم مليء بالمسام. لا أنسجة حقيقية ولا أعضاء.
Structure
Asymmetrical. Choanocytes (collar cells) create water flow. Spicules for support.
بلا تناسق. خلايا ياقوية تُحدث تيار مائي. شوكيات للدعم.
Coelom
Acoelomate (no coelom).
لا تجوف (acoelomate).
Function
Filter feeders — water in through pores, out through osculum.
تتغذى بالترشيح — ماء يدخل من المسام ويخرج من الفتحة العلوية.
Memory 🧠
Sponge = Pores everywhere, no true tissues, collar cells!
الإسفنج = مسام في كل مكان، بدون أنسجة حقيقية!
🪼 Cnidaria — اللاسعات
Key ID
Stinging cells (nematocysts) + Radial symmetry.
خلايا لاسعة (نيماتوسيست) + تناسق شعاعي.
Structure
2 body layers (diploblastic): ectoderm + endoderm. Gastrovascular cavity.
طبقتان جسميتان: أديم خارجي + أديم داخلي. تجويف معدي وعائي.
Coelom
Acoelomate (no true coelom).
لا تجوف حقيقي.
Examples
Jellyfish (medusa), Sea anemone & Coral (polyp).
قنديل البحر (ميدوزا)، شقائق النعمان والمرجان (بوليب).
Memory 🧠
C = Sting Cells + raDialsymmetry → Jellyfish!
اللاسعات = خلايا لاسعة + تناسق شعاعي = قنديل البحر!
🪱 Platyhelminthes — الديدان المفلطحة
Key ID
Flat body + No coelom (acoelomate) + Flame cells for excretion.
جسم مفلطح + لا تجوف + خلايا لهبية للإخراج.
Structure
Triploblastic (3 layers). Bilateral symmetry. Incomplete digestive system.
ثلاثي الطبقات. تناسق ثنائي. جهاز هضمي غير كامل.
Coelom
Acoelomate — no body cavity.
لا تجوف — بدون تجويف جسمي.
Examples
Tapeworm, Planaria, Liver fluke.
الديدان الشريطية، البلاناريا، الديدان الكبدية.
Memory 🧠
FLAT + FLAME + no coelom = Platyhelminthes!
مفلطح + خلية لهبية + لا تجوف = ديدان مفلطحة!
🔵 Nematoda — الديدان الأسطوانية
Key ID
Round worms + Pseudocoelom + Cuticle (tough outer layer).
ديدان مستديرة + تجوف كاذب + كيوتيكل (طبقة خارجية صلبة).
Structure
Triploblastic. Complete digestive system (mouth + anus). Bilateral symmetry.
ثلاثي الطبقات. جهاز هضمي كامل (فم + فتحة شرجية). تناسق ثنائي.
Coelom
Pseudocoelomate — false body cavity (not lined by mesoderm).
تجوف كاذب — لا يبطّنه الأديم المتوسط.
Examples
Roundworm (Ascaris), Pinworm, C. elegans.
الإسكارس، دودة الدبوس، C. elegans.
Memory 🧠
ROUND + PSEUDO + CUTICLE = Nematoda!
مستديرة + كاذب + كيوتيكل = نيماتودا!
🪱 Annelida — الديدان الحلقية
Key ID
Segmented body + True coelom + Nephridia (excretory organs).
جسم مقطّع + تجوف حقيقي + نيفريديا (أعضاء إخراجية).
Structure
Triploblastic. Closed circulatory system. Chaetae (bristles) in most.
ثلاثي الطبقات. دورة دموية مغلقة. شعيرات (حريشيات) في معظمها.
Coelom
True coelomate — coelom fully lined by mesoderm.
تجوف حقيقي — مبطّن بالكامل بالأديم المتوسط.
Examples
Earthworm, Leech, Polychaetes (marine worms).
دودة الأرض، العلقة، البولكيتات (ديدان بحرية).
Memory 🧠
SEGMENTS + TRUE coelom + NEPHRIDIA = Annelida!
حلقات + تجوف حقيقي + نيفريديا = حلقية!
🐌 Mollusca — الرخويات
Key ID
Soft body + Mantle + Radula (feeding organ) + Shell (usually).
جسم رخو + وشاح + رادولا (عضو تغذية) + صدفة (عادةً).
Structure
Triploblastic. True coelom. Open circulatory system (except Cephalopoda).
ثلاثي الطبقات. تجوف حقيقي. دورة دموية مفتوحة (عدا الرأسقدميات).
Coelom
True coelomate.
تجوف حقيقي.
Examples
Snail (gastropod), Clam (bivalve), Octopus/Squid (cephalopod).
الحلزون، المحار، الأخطبوط والحبّار (رأسقدميات).
Memory 🧠
MANTLE + RADULA + SHELL = Mollusca!
وشاح + رادولا + صدفة = رخويات!
🦗 Arthropoda — مفصليات الأرجل
Key ID
Exoskeleton (chitin) + Jointed appendages + Open circulatory system.
هيكل خارجي (كيتين) + زوائد مفصلية + دورة دموية مفتوحة.
Structure
Triploblastic. True coelom. Segmented body. Compound eyes.
ثلاثي الطبقات. تجوف حقيقي. جسم مقطّع. عيون مركبة.
Classes
Insecta (6 legs) • Arachnida (8 legs) • Crustacea (10+ legs) • Myriapoda (many legs).
الحشرات (6 أرجل) • العنكبوتيات (8) • القشريات (10+) • كثيرات الأرجل.
Memory 🧠
EXOSKELETON + JOINTED legs = Arthropoda! Largest phylum!
هيكل خارجي + أرجل مفصلية = مفصليات! أكبر شعبة!
⭐ Echinodermata — شوكيات الجلد
Key ID
Water vascular system + Radial symmetry (adults) + Spiny skin.
جهاز وعائي مائي + تناسق شعاعي (البالغ) + جلد شائك.
Structure
Triploblastic. True coelom. Deuterostomes. Tube feet for movement.
ثلاثي الطبقات. تجوف حقيقي. ثانويات الفم. أقدام أنبوبية للحركة.
Coelom
True coelomate. No head, no brain.
تجوف حقيقي. بلا رأس، بلا دماغ.
Examples
Starfish, Sea urchin, Sea cucumber, Brittle star.
نجم البحر، قنفذ البحر، خيار البحر، أفيورا.
Memory 🧠
WATER VASCULAR + SPINY + RADIAL = Echinodermata!
جهاز مائي + أشواك + شعاعي = شوكيات!
